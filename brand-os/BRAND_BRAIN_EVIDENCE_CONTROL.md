# RCG Brand Brain — Evidence & Publishing Control v0.1

Status: INTERNAL DRAFT — NOT APPROVED FOR EXTERNAL MARKETING  
Purpose: keep public claims, research, SEO metadata, collateral and future editorial output internally consistent and traceable.

## 1. Evidence hierarchy

Use the highest available tier before publishing a material claim:

1. Regulatory / primary records
2. Custodian, administrator, account or other authoritative operating records
3. Internally reproducible calculations tied to source data and methodology
4. Approved RCG methodology / policy
5. Contemporaneous RCG research with source provenance
6. Credible third-party reporting
7. Narrative interpretation / opinion

A lower-tier source must not silently override a higher-tier source.

## 2. Claim classes requiring evidence control

Treat these as controlled claims:
- performance, benchmark and drawdown figures
- AUM / assets / account counts
- inception and strategy-live dates
- audited / verified / composite / track-record descriptions
- registration and jurisdiction statements
- personnel titles, roles, credentials and biographies
- office/location/address statements
- awards, rankings and third-party recognition
- client or investor descriptions
- investment-process superlatives and comparative claims

## 3. Required claim record

For each controlled claim retain:
- exact claim text
- claim owner
- evidence source
- evidence tier
- as-of date / measurement period
- methodology where calculated
- approved public wording
- approved channels
- superseded wording, if any
- reviewer / review date
- next review trigger

If two controlled artifacts disagree, create an evidence exception. Do not choose whichever number or wording is more favorable.

## 4. Vocabulary controls

### Red until evidenced
Do not use these as factual marketing descriptors without documentary support specific to the claim:
- audited
- verified
- composite
- independently verified
- institutional-grade
- best / leading / superior
- proven

### Yellow — requires context
- live
- track record
- proprietary
- risk-adjusted
- absolute return
- downside protection
- uncorrelated
- institutional

### Green — still must be accurate
Plain descriptions of documented structure, process, geography and roles that are supported by current primary records.

## 5. Performance-control rule

Every public performance presentation should resolve to one canonical performance source and one methodology record. A performance number should never be manually re-keyed across multiple PDFs/pages without reconciliation.

Minimum metadata:
- strategy
- period
- gross/net status
- fee treatment
- account/model/proxy/composite status
- benchmark
- calculation methodology
- source dataset/version
- approval date
- superseded version

Do not imply an all-account composite exists or is available unless that composite has actually been constructed, reviewed and can be furnished as represented.

## 6. Controlled collateral inventory

Every externally reachable PDF/deck/tear sheet/white paper should have:
- document ID
- title
- version/date
- canonical URL
- owner
- status: draft / approved / superseded / archived
- performance vintage
- methodology reference
- disclosure version
- public-link locations
- retirement date, if superseded

Superseded material may need to be retained for records while being removed from active public distribution.

## 7. Website / SEO identity controls

Maintain one canonical machine-readable identity for RCG. Structured data, visible copy, social metadata and controlled profiles should not contradict one another.

Preferred public geography where a street address is not required:
**Miami Beach, Florida**

Do not voluntarily propagate residential/unit-level addresses or exact coordinates through SEO metadata when not necessary.

Identity should consistently distinguish:
- Robin Capital Group LLC / RCG
- Nicolas Diaz / Nick Diaz
- founder / CIO role
- advisory personnel
- compliance / operations personnel
- affiliates and external relationships

Avoid generic plural terms such as "principals" when they create ambiguity about advisory responsibility.

## 8. Editorial evidence tags

Draft research should tag substantive statements:
- FACT
- CALCULATION
- INFERENCE
- OPINION / FORECAST

Before external use, factual and calculated claims must retain source provenance. Forecasts must not be rewritten as facts after the event.

## 9. Story Vault fields

For each reusable RCG story:
- story ID
- event/date
- source evidence
- what happened
- what RCG believed at the time
- decision/action
- outcome
- lesson
- approved public angle
- sensitive/non-public elements
- compliance notes
- reusable formats: article / interview / website / deck / social

The Story Vault is not a mythology engine. Outcomes should preserve contemporaneous uncertainty and failed reasoning, not only successful calls.

## 10. Current evidence exceptions to resolve

These are review items, not approved conclusions:

1. Website/collateral use of "audited" must be reconciled to documentary evidence defining what was audited, by whom, for what accounts/periods and under what standard.
2. Public performance collateral must be reconciled where different document versions report different figures for the same strategy/period.
3. Any statement that composite returns are available on request must be tied to an actually maintained, reviewable composite before publication.
4. Publicly linked January 2026 investor-deck versions should be inventoried and assigned canonical/superseded status.
5. Public address/location representations should be normalized across website, structured data, controlled profiles and regulatory-required disclosures without overwriting legally required addresses.
6. Duplicate website artifacts such as `index (4).html` require provenance/status before deletion or reuse.

## 11. Publishing gate

Before external publication:
1. identify controlled claims;
2. attach evidence;
3. reconcile conflicts;
4. confirm current disclosure language;
5. confirm document/version status;
6. perform compliance review where required;
7. preserve the approved artifact and evidence trail.

No external publication is authorized by this document.
